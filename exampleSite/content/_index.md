# *This... Is* Steel*on Musk*
A compact theme with a tabular layout, designed to fit more text on the screen.

## Features
- Simple and clear theme
- Compatibility with older browsers
- Customizable header and footer
- Easy-to-modify theme

## Installation
Simply copy this repository and unpack it into your Hugo site. To configure the header or footer, you can follow [this link](/blog/header-footer.md).
